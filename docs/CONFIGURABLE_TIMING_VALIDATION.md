# 可配置调度与阶段计时

默认进程数为 min(12, 逻辑线程数)，条带数 0 表示 min(所选列数, 3 × 请求进程数)。进程从共享队列动态领取条带；全图模板/空间拟合和 Stage 2 使用同一工作池。

计时采用互斥的主任务墙钟阶段，保存回调从当前计算阶段中扣除，后台工作进程仍可能继续计算。因此不能把保存占比当作增加进程后可消除的耗时。各阶段与 other_seconds 相加等于 wall_seconds。计时截止到主体 ZIP 压缩完成，随后写入计时元数据并提交归档。

API、磁盘与 ZIP 保留相同计时快照；旧记录不补造缺失时间。相关断言见 `tests/test_timing.py` 与 `tests/test_api.py`，公开测试结果见 [PUBLICATION.md](../PUBLICATION.md)。本地历史记录中的私人样本、截图及工具运行细节未公开。
