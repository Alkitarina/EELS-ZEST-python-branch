# 本机检测与空间分块验证 · 1.1.0

## 行为与兼容性

- 设备配置只在后端启动或手动点击「重新检测」时更新，健康检查和配置读取返回缓存快照。
- 默认工作进程数为 `min(61, max(1, 逻辑线程数 − 2))`，自动目标块数为 `max(1, 3 × 请求进程数 − 4)`，实际块数受像素数或切分方向限制。手动并行数保留，界面支持恢复推荐值，配置变更不改写运行中的任务。
- 默认按相邻空间蛇形路径均分像素，各块最多相差 1 个像素；支持完整竖条、完整横条和手动行 × 列网格。余数分散到不同块，无需整除图像尺寸。
- 热图按实际像素归属绘制边界，支持非矩形块。分块边界不会成为新的空间拟合屏障。
- 保留 `execution_mode="stripes"`、`stripe_count` 和执行记录的 `stripes` 字段。复现旧式竖条请求需显式指定 `partition_mode="vertical"`。

发布准备前，开发环境的三个互不重叠 Python 测试批次共 **85 passed**，前端逻辑测试 **28 passed**。其中部分数值测试使用本地 MATLAB 参考数据和可选原生扩展；数据、编译产物、截图及运行结果不随公开仓库分发。

- 分块测试覆盖质数尺寸、单行 / 单列、ROI、稀疏坐标、余数均分、蛇形相邻性、非矩形真实边界及坐标覆盖。
- 实际多进程测试覆盖四种分块、动态领取、坐标映射、取消后的非连续保存、跨块全图空间上下文、Stage 2 续算和 ZIP 导出。

- 全图层级拟合使用同一批 Stage 1 输入对照，串并行接受数、阶段顺序和数值一致，内部像素保留全部八邻域。Stage 2 使用同一批磁盘 Stage 1 输入时，串并行温度逐项一致。
- 界面测试覆盖自动 / 手动设置持久化、刷新保留手填值、不改运行任务、网格预览、Stage 2 参数处理、边界显示、断线恢复和旧后端保护。
- 浏览器中完成小样本的两阶段网格计算、保存和刷新恢复；验证横纵边界与手动设备检测，无 JavaScript 错误。

## 科学与性能限制

分块管理 Stage 1 求解顺序和相邻热启动，不按谱线相似度拼接远距离像素。真正的聚类、模板、界面屏障、跨块邻域与四色同步仍在全图上下文执行。每块首像素、失败后的像素和跨坐标间隙的像素执行完整初始化。没有更换求解器、放宽容差、减少块首优化轮次或修改温度扫描模型。

**不同分块之间的 Stage 1 初值路径不同，最终局部解和温度不保证一致。** 更多块增加完整初始化次数，像素数均等也不代表计算时长相等；`3n−4` 是启发式默认值，并非最优分块数或已证实的加速倍数。本次没有运行完整真实谱像的性能与温度可靠性基准。
